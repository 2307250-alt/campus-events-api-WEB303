WEB303 Team Project

This project is a team assignment for PHP using technologies like Laravel, Postman, and deployed online.

Tech Stack
- PHP / Laravel
- Postman - API Testing
- Composer - Dependency management

Prerequisites:
- PHP 8.1 or higher
- Composer

Installation:
1. Clone the repo with "git clone https://2307250-alt/campus-events-api.git" then enter directory with "cd campus-events-api"
2. Install PHP dependencies with "composer install"
3. Change environment file .env.example to .env, and run "php artisan key:generate"
4. configure .env and run "php artisan migrate"
5. Start the development server with "php artisan serve" and go to http://localhost:8000 or http://127.0.0.1:8000
